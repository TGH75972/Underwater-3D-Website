<h1>Underwater 3D Website</h1><br>

<b>This project utilizes 3js to add an underwater canvas to the website along with 3D objects like submarine, rocks, coral reefs, particles, to give the user the experience of deep sea while surfing the website</b> <br>

<b>A 3D model of glb format named red_coral.glb can be added to the models folder to add custom 3D models to the website!</b>
